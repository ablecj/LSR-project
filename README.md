# LRS — Legal & Relocation Services (Next.js App Router Website)

An art-directed, bilingual (English & മലയാളം) corporate website built with **Next.js (App Router)**, **React**, **TypeScript**, **Tailwind CSS**, **GSAP + ScrollTrigger**, **Lenis Smooth Scroll**, **Swiper.js**, and **Lucide React**.

## 1. Brand Color System (Extracted from `LRS.png`)
- **Primary Deep Petrol Teal (`--brand-primary`)**: `#0B5C70` (`rgb(11, 92, 112)`)
- **Secondary Vibrant Aqua (`--brand-secondary`)**: `#10A5AC` (`rgb(16, 165, 172)`)
- **Deep Architectural Backdrop (`--brand-primary-deep`)**: `#052C36`
- **Primary Surface (`--brand-surface`)**: `#FFFFFF` (Pure White)
- **Muted Editorial Surface (`--brand-surface-muted`)**: `#F6F9FA`

## 2. Quick Start
```bash
npm install
npm run dev
```
Build for production:
```bash
npm run build
npm run start
```

## 3. How to Replace Sample Content & Translations
- **Hero Slides, Practice Areas, and Team Members**: Edit `src/data/siteContent.ts`.
- **English & Malayalam UI Copy and Contact Coordinates**: Edit `src/data/translations.ts`.
- **Logo & Photography Assets**: Located in `public/images/` (`lrs-logo.png`, `lrs-logo-light.png`, `hero-1.jpg`..`hero-3.jpg`, `about-editorial.jpg`, `service-*.jpg`, `team-*.jpg`).
